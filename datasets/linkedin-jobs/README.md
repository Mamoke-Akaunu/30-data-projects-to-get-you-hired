# LinkedIn Job Market

**Project role:** Recruitment and job-market intelligence.

**Source files expected:** One CSV with job listings, employer details, applications and free-text role information. Repeated job IDs require investigation before deduplication.

**Privacy:** Do not publish hiring-person names, personal profile URLs or unnecessary job-description text in a public sample.

**Licence/provenance:** Open Data Commons DbCL cited by uploader; it does not itself establish permissions over the LinkedIn-sourced content. File not yet published.
