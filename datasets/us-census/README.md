# U.S. Census State Indicators

**Project role:** State-level demographic and economic comparisons using historical U.S. Census observations.

## Files
- `US_Census_Data.csv` — original uploaded data, provided as CSV text even though its source filename ended `.csv.xls`.

## Important notes
- Main table has 50 state columns, and 65 indicator rows. Remaining lines are notes, definitions and value flags; do not analyse them as observations.
- Some indicators reference different time periods. Do not interpret the file as an annual time series.
- Interpret suppression and value flags using the source definitions, not as zero.

**Rights:** Census data is generally public domain as a U.S. federal government work, but the compilation was described by the uploader as MIT-licensed; verify provenance and preserve any accompanying notices.
