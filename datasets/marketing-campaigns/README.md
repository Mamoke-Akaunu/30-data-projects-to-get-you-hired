# Messy Marketing Campaigns

**Project role:** Campaign performance and data quality.

**Source files expected:** One campaign CSV with intentionally inconsistent values, duplicate IDs, missing conversions, mixed status labels and invalid dates/spend. Report conversion rate, CTR, CPC and CPA only when denominators and definitions are valid. No sales-revenue field means ROAS is unavailable.
