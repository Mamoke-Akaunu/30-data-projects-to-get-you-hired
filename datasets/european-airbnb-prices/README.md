# European Airbnb Accommodation Prices

**Project role:** Accommodation pricing and location comparisons across nine European cities.

**Source files expected:** A single listings dataset (original file name: `Aemf1.csv`). It includes prices, city, weekday/weekend, room type and distance to centre. It does **not** report bookings, occupancy or realised revenue.

**Licence/provenance:** CC0 reported; independent source verification pending. Files not yet published.
