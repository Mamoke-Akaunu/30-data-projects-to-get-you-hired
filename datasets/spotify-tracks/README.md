# Spotify Tracks: Hits vs Flops

**Project role:** Music audio-feature trends and descriptive catalogue analysis.

**Source files expected:** Six decade-specific CSVs (1960s through 2010s). The balanced hit/flop sampling means label proportions are not population hit rates; repeated track URIs must be handled deliberately.
