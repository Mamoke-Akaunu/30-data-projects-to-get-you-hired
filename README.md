# 30 Data Projects to Get You Hired

A practical portfolio companion for aspiring data analysts learning **Excel, SQL and Power BI**.

This public repository will accompany the ebook *30 Data Projects to Get You Hired*. It is being built progressively. Project briefs, starter files, approved datasets and reproducible instructions will be added as the book is developed.

- [Excel projects](excel-projects/README.md) — 10 portfolio projects
- [SQL projects](sql-projects/README.md) — 10 portfolio projects
- [Power BI projects](power-bi-projects/README.md) — 10 portfolio projects
- [Dataset catalogue](datasets/README.md) — source, licence, schema and cleaning notes for each dataset
- [Learning resources](resources/README.md) — setup and portfolio guidance

## How the repository is organised

Each project will have its own numbered folder, business brief, ten progressive questions, starter materials, and relevant dataset references. Where a source contains several related files, they will be grouped in a dataset-specific folder with a README explaining relationships and data quality.

## Dataset use and licensing

**Do not assume every third-party dataset in the project plan is free to redistribute.** Public dataset files will only be added when suitable distribution rights have been established. Where rights are uncertain, the project may instead contain source/download instructions, a properly licensed replacement or an original synthetic sample.

Dataset licences and source attributions will be documented separately. The absence of a general repository licence does not grant permission to reuse third-party data.
